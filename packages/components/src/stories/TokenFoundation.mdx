# Tokens

The approved default FDS v1 token foundation uses light mode, IBM Plex Sans Condensed, and compact desktop density. Components consume semantic roles; raw values remain in primitives, and component tokens exist only for stable repeated decisions. Dark mode is outside the current foundation.
