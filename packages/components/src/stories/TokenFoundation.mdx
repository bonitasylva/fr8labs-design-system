# Tokens

<p className="fds-token-docs__intro fds-token-docs__foundation-intro">FDS v1 is a light, compact foundation. Tokens resolve inside an <code>fds-root</code> subtree: product code uses semantic roles, primitives supply raw scales and functional measurements, and component tokens stay internal. The shipped theme is <code>default</code>; a future tenant theme may override only the approved semantic brand roles, never primitive or component tokens.</p>
